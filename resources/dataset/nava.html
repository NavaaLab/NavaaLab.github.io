Nava Dataset

The Nava Dataset is an important resource for Instrument and Dastgah Recognition in Persian Traditional Music. It consists of around 40 hours audio excerpts tagged for 7 'Dastgah's and 5 instruments in Persian traditional music.

If you are interested in using this dataset for your research, please submit the request form below. By requesting access, you agree to use the data only for academic and research purposes.

For more details, you can read the original paper here: Nava Paper.
